# 80sloupcová karta K&P (MZ-700) - uživatelská dokumentace

80-Zeichen-Karte firmy Kersten & Partner je rozšiřující karta pro Sharp
MZ-700. Má vlastní CRTC (Synertek SY6845E), vlastní videopaměť 2 KB,
vlastní generátor znaků a **vlastní video výstup na druhý monitor**:
80 x 25 znaků po 8 x 10 bodech (640 x 250 bodů, zhruba 50 Hz,
jednobarevně). Obraz MZ-700 se nemění; oba obrazy existují vedle sebe
a software volí, kam píše (například `SCREEN 0` / `SCREEN 1` v K&P Disk
BASICu). Karta nemá grafiku, jen znaky.

Karta je jen v emulátoru MZ-700 (PAL i NTSC).

> **Poznámka:** autor emulátoru tuto kartu nikdy neviděl. Model stojí jen
> na rešerši informací z internetu (dobový článek v časopise se schématem,
> datasheet CRTC a popis majitele karty). Na skutečném hardwaru se nic
> neměřilo. Podrobnosti, ve kterých se prameny rozcházejí, jsou volby
> (viz níže), ne ověřené vlastnosti hardwaru.

## Připojení karty

Menu **HW & Devices / K&P 80 Column Card / Connected**. Výchozí stav je
odpojeno. Volba se ukládá do souboru `.ini` (sekce `[KP80]`, klíč
`connected`).

Připojení karty je jako její zapnutí: registry CRTC jsou 0 a videopaměť
obsahuje 00h. Druhý monitor zůstane tmavý, dokud program CRTC nenastaví;
pak je obrazovka plná znaků `@` (kód 00h), dokud ji program nesmaže.

Software pro kartu (například K&P Disk BASIC) není součástí emulátoru.

## Druhý monitor

Okno **K&P 80 Column Monitor**:

- otevírá se položkou **HW & Devices / K&P 80 Column Card / Show 80 Column
  Monitor** a samo, když kartu připojíte za běhu emulátoru;
- jde zavřít a zvětšit; obraz drží poměr stran monitoru 4:3;
- jestli je otevřené, se ukládá do souboru `.ini` (sekce `[KP80_UI]`).

Barvu fosforu monitoru (bílá, zelená, jantarová) volí volba **Monitor
phosphor color**. Mění jen zobrazení, ne kartu.

## Volby

Menu **HW & Devices / K&P 80 Column Card**. Všechny volby platí hned.

| Volba (klíč v INI) | Výchozí | Význam a proč tato výchozí hodnota |
|--------------------|---------|-------------------------------------|
| Read from 70h increments the address (`read_autoinc`) | zapnuto | Čtení videopaměti portem 70h posune adresu na další bajt. Tak to uvádí datasheet CRTC; software majitele karty nastavuje adresu před každým čtením, takže na tom nezávisí. |
| Write to 71h also writes the selected CRTC register (`data_to_reg`) | zapnuto | Podle schématu se bajt zapsaný na 71h dostane i do vybraného registru CRTC. Známý software před zápisem vybírá registr 31, takže je to neškodné. |
| Update address (R18/R19) takes effect on R31 access (`addr_on_r31`) | zapnuto | Nová adresa ve videopaměti platí až po přístupu k registru 31, jak to popisuje datasheet i majitel karty. Vypnuto = adresa platí hned. |
| Update cycle length (character clocks) (`update_delay`) | 0 | Jak dlouho zůstane bit 7 statusu po přístupu do videopaměti 0 (znakový takt = 2 MHz). Skutečné časování není známé; 0 = vždy připraveno. |
| WAIT on ports 71h - 73h (T-states) (`wait`) | 0 | Karta na těchto portech krátce pozdrží CPU signálem WAIT; délka není známá. 0 = bez zdržení. |
| Monitor phosphor color (`phosphor`) | white | Barva zobrazení druhého monitoru: v menu White, Green, Amber (v INI `white`, `green`, `amber`). |

V souboru `.ini` se čísla `update_delay` a `wait` čtou šestnáctkově
(`wait = 10` znamená 16).

## Porty a registry (pro programátory)

| Port | IN | OUT |
|------|----|-----|
| 70h | bajt videopaměti na update adrese | - |
| 71h | vybraný registr CRTC | bajt do videopaměti na update adresu, adresa se posune na další bajt (volbou i do vybraného registru) |
| 72h | status: bit 7 update ready, bit 6 světelné pero (vždy 0), bit 5 vertikální zatemnění | výběr registru CRTC (bity 0 - 4) |
| 73h | vybraný registr CRTC | vybraný registr CRTC |

Porty jsou dekódované úplně (bez zrcadel).

Do videopaměti se přistupuje jen přes CRTC (transparentní režim, R8 =
78h): R18/R19 = adresa, přístup k R31 adresu potvrdí, bit 7 statusu =
připraveno. Postup zápisu:

```
        LD   A,18          ; R18 = horní bajt adresy
        OUT  (72h),A
        LD   A,H
        OUT  (73h),A
        LD   A,19          ; R19 = dolní bajt
        OUT  (72h),A
        LD   A,L
        OUT  (73h),A
        LD   A,31          ; výběr R31 = potvrzení adresy
        OUT  (72h),A
RDY:    IN   A,(72h)       ; čekat na update ready
        RLCA
        JR   NC,RDY
        LD   A,'A'
        OUT  (71h),A       ; znak do videopaměti, adresa + 1
```

Inicializace, kterou používá software majitele karty, R0 - R15: `7Fh 50h
64h 0Ch 1Eh 02h 19h 1Ch 78h 09h 60h 09h 00h 00h 00h 00h` (80 x 25, 10
řádků na znak, blikající kurzor). Začátek obrazu R12/R13 (posun obrazu:
přičíst 80, modulo 2048), poloha kurzoru R14/R15, tvar kurzoru R10/R11.

Číst jdou registry R14 - R17; ostatní registry se čtou jako 0.
Videopaměť má 2048 bajtů, adresy se berou modulo 2048.

## Font a znaky

Generátor znaků je zabudovaný v emulátoru (EPROM karty, 128 znaků po
8 x 16 bodech, obraz používá 10 řádků z každého). Kódy 00h - 7Fh jsou
německá varianta ASCII (například 40h = `§`, 5Bh - 5Dh = `Ä Ö Ü`,
7Bh - 7Eh = `ä ö ü ß`). Bit 7 kódu zobrazí znak inverzně.

## Zapnutí a reset

- Připojení karty = zapnutí: registry 0, videopaměť 00h, tmavý monitor.
- **Reset** MZ-700 kartu nemaže: registry i videopaměť zůstanou a druhý
  monitor drží obraz, dokud software kartu znovu nenastaví. (Volba
  modelu: podle datasheetu reset CRTC zastaví jen čítače.)

## Snapshoty a debugger

- Snapshot (`.mzs`) ukládá, jestli je karta připojená, její volby,
  registry a videopaměť.
- Debugger: okno I/O ukazuje porty 70h - 73h v sekci Expansion devices;
  Memory Browser ukazuje videopaměť karty (zapisovatelná), font a registry
  CRTC (jen čtení).
- MCP: obraz druhého monitoru vrací nástroj `emu_device_screenshot` (viz
  dokumentace MCP).
